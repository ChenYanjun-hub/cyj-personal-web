# 作品集网站开发日志

**日期**：2026年4月17日

---

## 背景

计划从零定制一个网页版简历 + 作品集网站，目标是"高级感"和"艺术审美在线"。

---

## 方案调研

### 实现路径对比

| 方案 | 难度 | 适用场景 |
|------|------|----------|
| Vercel + 模板 | 简单 | 快速上线，定制受限 |
| Framer / Webflow | 简单 | 无代码拖拽，自定义有限 |
| Next.js + Tailwind | 中等 | 完全定制，开发者友好 |
| 从零手写 | 较难 | 最大灵活性 |

**决定**：从零定制

---

## 难度分析

### 技术实现 vs 设计审美

**技术层面** — 不难
- 动效、过渡、滚动效果 → Framer Motion / GSAP
- 3D 元素 → Three.js / React Three Fiber
- 高级排版 → CSS Grid / 自定义字体
- 成熟库可覆盖 95% 效果

**设计层面** — 核心难点
- 视觉层次：留白、对比、节奏感
- 排版：字体搭配、字号比例、行距
- 配色：高级感来自克制，而非花哨
- 动效节奏：不动太死板，动太多显廉价
- 作品展示：每个项目的呈现方式需精心设计

## 技术路线确定

| 层面 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js + React | 主流、生态好、部署简单 |
| 样式 | Tailwind CSS | 直接写设计，无需传统 CSS |
| 动效 | Framer Motion | 声明式，符合设计直觉 |
| 部署 | Vercel | 免费，一键部署 |
