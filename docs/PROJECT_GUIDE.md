## 0. 一句话项目定位

一个用于求职的个人网页,定位是「**递给 HR 的数字名片**」。核心人物是一位 **城乡规划师转型 AI 产品经理(AIPM)** 的求职者,求职方向为 **通用 AIPM,以 B/G 端为主、C 端为辅(对 C 端有强烈意愿挑战)**。

网页要传达的核心信息:**「我有一套别人没有的认知操作系统(规划师的系统思维),并且能亲手把 AI 产品做出来。」**

> 设计哲学:本网页的「形式」本身就是「能力的证明」——用一个自己 vibe coding 做出的、带可用 AI 分身的网站,证明"我懂 AI 产品、能动手落地"。内容是 1,炫酷交互是后面的 0;先把 1 立住。

---

## 1. 目标用户与设计原则

### 目标用户
- 主要:招聘 AIPM 的 HR 与用人经理(很可能用**手机**浏览 → 移动端必须可用)。
- 浏览场景:碎片化、几十秒快速判断「这人是否值得约面」。
- 求职地理范围:上海、长三角(无锡、苏州、杭州、南京等)。

### 核心设计原则
1. **聚焦胜于全面**:信息越聚焦越有杀伤力,避免「全能型简历」的同质化。该砍的忍痛砍。
2. **诚实优先**:宁可少而真,不要多而虚。承认短板反而增强可信度。所有内容经得起面试追问。
3. **主次分明**:两个深度项目重点呈现,三个探索项目轻量化,绝不平铺。
4. **形式服务叙事**:交互动效要服务于信息传达,不为炫技而炫技。
5. **风格基调**:苹果官网式纵向滚动叙事 + 极简留白 + 克制配色 + "空间/城市/规划"线稿视觉母题贯穿全站。

## 2. 技术方案

> **核心约束:网页面向国内 HR,必须保证国内稳定访问。** 因此整站 + AI 分身全部走"国内闭环",不依赖任何在国内访问不稳定的境外服务(Vercel、Anthropic API 等均已排除)。
>
> 负责人已有阿里云服务器,并在"云上米轨"项目中跑通过 Next.js + Node + PM2 + Nginx 的自部署,故以下方案对负责人不是新坑。

### 双目标说明
本项目有两个目标:**①(主)尽快做出好用的求职网页;②(次)借项目练手 Supabase。** 原则:**让练手发生在不阻塞主线的支线上**,绝不为练技术把简单的事搞复杂。

### 技术选型
- **框架**:Next.js 16(App Router)— 传递"懂现代前端工程、能与工程师同频"的正向信号;负责人已驾驭其自部署。
- **样式**:Tailwind CSS v4。
- **TypeScript**:启用(2026 年标配，实际版本 6.0.x)。
- **Bundler**:**Webpack(V1)**——本机环境踩到 Turbopack 文件监听越界 → 内存爆 60GB 卡死，已切回 webpack 兜底。详见 `dev-log.md` 阶段一 / 踩坑 3.1。`bundler` 字段保留可切换，未来 Turbopack 修复或环境隔离更彻底后再切回。
- **部署**:**阿里云服务器**(Node + PM2 + Nginx)+ **域名 `cyjpersonalweb.cn`**(ICP 备案进行中)。
- **AI 分身后端(V1,主线)**:用 **Next.js 自带 API Route** 做"密钥代理"——前端把问题发给本站 `/api/chat`,服务端持密钥调大模型,返回结果。**不引入 Supabase**(分身本质是安全调模型,不需要数据库)。
- **AI 分身模型**:**国内大模型 API**(首选 DeepSeek,性价比高;通义千问 / 智谱 GLM / Kimi 均为候选,开工时实测选定)。该场景(基于资料诚实答问 + JD 匹配)不需顶尖推理,只需"听话、不乱编、能被系统提示词约束",国内模型完全够用,且国内访问稳定、便宜。
- **留言系统(V2,练手主战场)**:用 **Supabase** 存留言 + 做审核(练 CRUD / Auth / RLS)。**关键:经 Next.js 后端中转**(前端 → 本站阿里云后端 → Supabase),不从前端直连 Supabase——既保证国内可达(Supabase 是境外服务,浏览器直连国内不稳),又练到"后端集成第三方数据库"这一更有含金量的技能。

### 架构铁律(现在就定,贯穿始终)
1. **模型调用做成可替换层**:把"调哪个大模型"封装成独立模块,换模型只改这一处(API 地址、密钥、请求格式),其余代码不动。便于在不同国内模型间切换。
2. **密钥只在服务端**:所有 API 密钥放服务器环境变量,**绝不出现在前端代码**(会被任何人看到、盗刷)。
3. **前端只与自己的阿里云后端通信**:分身、留言等所有需要密钥或访问境外服务的请求,一律经本站后端中转,前端不直连任何境外服务。

### 其他关键约束
- 负责人前端交互经验尚浅,采用 vibe coding 方式推进,代码需**结构清晰、注释充分、便于理解和增量修改**。
- 移动端适配是一等公民,不是事后补丁。每一幕都要考虑触屏与窄屏。
- **国内可达性是硬指标**:任何功能上线前,都要确认国内能稳定打开/调用。

## 4. 各幕详细规格

### 🤖 全站组件:AI 数字分身

**定位**:帮 HR 快速、诚实地了解"本人是否值得约面"的助手。目标不是讨好,是高效促成"约你聊一聊"。

**交互**:右下角固定泡泡 → 点击展开小 chat 栏。

**两个核心能力(范围收敛,只做这两件)**:
1. **诚实答问**:基于真实资料回答关于本人的问题。
2. **诚实 JD 匹配**:HR 粘贴岗位 JD,分析匹配度。

**降低门槛**:展开后提供预设问题(如"他的核心优势是什么?""他为什么从规划转行?")+ JD 输入框。

**关键约束(防翻车,这是 AIPM 能力的体现)**:
- **严防幻觉**:系统提示词严格限定只能基于提供的真实资料回答;资料里没有的,如实说"这部分建议直接和本人聊",**绝不编造**。
- **JD 匹配做诚实版**:诚实分析——高度匹配项给证据,成长项坦诚承认 + 说明如何补。绝不永远给"95% 超级匹配"。
- **匹配分析以"诚实 + CTA"收尾**:结尾生成一句既自信又诚实、顺势引导约面的话。
- **成本与滥用防护**:限制单次对话长度、限制频率,防止恶意刷量产生意外 API 费用。
- **话题收束**:被问到无关/刁钻问题时,得体地拉回"了解本人求职能力"。

**技术实现**:前端 → 本站 Next.js API Route(`/api/chat`,持密钥)→ 国内大模型 API(首选 DeepSeek)。模型调用走"可替换层",便于切换。密钥只在服务端。

**知识库来源**:`【待回填:本人完整简历 + 本文档所有真料 + 单独维护的"分身知识库采集清单.md"】`(负责人已在自己的 .md 文档中维护,作为单一真相源)

**隐私边界**:`【已定:不公开手机号/微信,由分身经邮箱做中介;具体清单见分身知识库】`

### 第一幕:Hero · 数字名片

**唯一目标**:HR 滑过这屏后,脑子里留下一个清晰的"你"。视觉是钩子,钩子上挂着信息。

- **主体**:中文名"陈彦均"为主,英文 "CHEN YANJUN" 作辅助层次(解决中文方块字撑不起超大字母张力的问题,用留白 + 设计感字体 + 英文辅助)。
- **背景(V2 加)**:那张 AIGC 城市轴测线稿图,做成极淡的空间感肌理(约 5-10% 透明度)+ 鼠标视差(背景比前景慢半拍)。**V1 先用纯白/极浅灰,把文字层做对再加背景。**
- **身份标签行**:点出反差,如 `城乡规划师 → AI 产品经理 / B·G 端 / 上海 · 长三角 · 寻找机会`。
- **一句话主张**:`【待回填:最终版】` — 灵魂是"无限进步"的精神(致敬影视飓风,但用本人自己的语言原创表达,不直接照搬 slogan)。占位:「从规划一座城,到构建 AI 产品」。
- **Scroll 引导**:保留,苹果式叙事标志元素。

> 注意:参考图是应届工程师,可纯视觉冲击;本人是转行者,Hero 必须额外承担"用一句话钉住反差感"的任务,不能只放大名字。

### 第二幕:能力对照(信任引擎)

**作用**:正面回答 HR 心中"你凭什么能跳过来"。用结构化证据让 HR 自己得出"他能行"的结论。

**形式**:双栏对照。左栏「城乡规划师的我」,右栏「这意味着我具备的产品能力」。**每组不只给词,要给具体场景**。

**五组对照**(具体场景已在分身知识库的 1.4 完成定稿,信阳柳林项目为主要素材):
1. **需求洞察**:现状调研、人口用地分析、小红书热度 ↔ 用户研究与需求洞察。
2. **多方博弈(最强项)**:政府/开发商/居民/生态多方平衡、信阳竞标 ↔ 利益相关方管理,在业务/技术/设计冲突中推动决策。
3. **从战略到落地的分解**:"信心主题"→24 个子项目→资金测算 ↔ 产品战略拆解为功能与迭代。
4. **系统与长期思维**:精神/用户/产品/商业/运营五层系统 ↔ 系统性产品思维。
5. **方案表达与共识**:用图纸/汇报向不同背景的人讲清方案 ↔ 跨职能沟通对齐。

**收尾(必须保留)**:一句"承认短板"的话,把短板转化为"有自知之明 + 用行动弥补",并自然引向第三/四幕。

**交互**:负责人有想法,开发时再具体讨论(思路:左栏先入,右栏逐条"翻译/浮现",模拟能力迁移)。

### 第三幕:能力技能(硬通货)

**作用**:与第二幕互补——第二幕讲"可迁移的软潜质",本幕讲"已掌握的 AI 时代硬技能"。一软一硬,递进不重复。

**表现形式铁律**:**绝不用百分比/星级/进度条**(无意义、掉价、对转行者危险)。用"能做成什么"的动词分级:
- 能独立做到 → "熟练""能独立完成"
- 能做但在加强 → "能运用""持续精进中"
- 了解原理没实操 → 诚实归为"了解/学习中"或不放

**四个板块(顺序即主次,AI 能力与动手能力前置)**——具体内容已在分身知识库第三类定稿:
1. **AI 产品能力**(核心):AI 知识体系搭建、RAG 应用设计、Prompt 工程、Agent 应用、AI 评估与质量管理、对 LLM/多模态能力边界的理解。
2. **产品设计与方法**:PRD 撰写(建景规)、竞品分析(10+ 维度)、用户研究、产品方案设计与原型(Figma)。
3. **技术与动手能力(差异化亮点)**:Vibe Coding(Claude Code + Cursor + VSCode)、AI 辅助下的产品架构能力、与工程团队协作的语言能力。
4. **专业领域 & 工具**:城乡规划专业(有论文成果)、GIS/空间数据分析、规划与设计软件(AutoCAD/SketchUp/Rhino/PS/AI 熟练)、AIGC 工具、知识管理与办公。

**交互**:分组卡片/标签,悬停展开"我用这个能力做过什么"的一句话。开发时定。

### 第四幕:作品集 · 城市规划图(证据高潮)

**核心策略**:主次分明,绝不平铺五个项目(避免"点开发现是空文件夹"的尴尬)。

**视觉外壳**:线稿风格城市规划图(呼应 Hero 母题),鼠标变**放大镜**勘察。
- **核心地块(2 个深度项目,画得饱满、可点击放大进入)**:云上米轨、建景规规范知识问答助手。
- **待建区(3 个探索项目,用虚线框/"规划中"标注,诚实表达"接下来要建")**:MOOGU 野生菌数字手帐、个人多 Agent 助手平台、合同审阅助手。
- **新增层级 · Agent 实验田**:Coze 上已发布的失恋陪伴助手、AI 情感伴侣等 V1。定位为"已发布但小、是探索性质",填补"已建成的大项目"和"待建区"之间的中间地带。
  > 此设计优雅消化了"项目没做完"——用"建成 vs 待建"的规划语言天然解释成熟度差异,把减分项变加分项,也展示了清晰的产品路线图。

**点进项目后的内容内核**:统一的产品案例拆解结构 → `项目一句话定位 → 背景/问题 → 我的角色与产品决策 → AI 技术范式 → 成果/现状 → 我的反思`。

**深度案例一:云上米轨**(BtoBtoC)
- 卖点:系统性 + 多方利益结构(呼应规划背景)
- 技术栈:Next.js 16 + React 19 + Tailwind v4 + Supabase + pgvector + DeepSeek + DashScope,含 7 用户端模块 + 5 角色 Admin + 6 角色 RLS
- `【待回填:完整事实档案,类似信阳柳林档案的深度】`

**深度案例二:建景规规范知识问答助手**(toB,RAG)
- 卖点:toB 能力最硬证据。重点讲清两件"分水岭问题":① 怎么解决幻觉;② 怎么定义"回答得好不好"(eval)
- 已有完整 PRD(含执行摘要、用户调研、10+ 维度竞品分析、理想态与评测、技术附录)
- 评测集 50 → 100 → 250 迭代中
- `【待回填:完整事实档案】`

**待建区三个项目的一句话技术判断**(`【待回填一句话】`):
- MOOGU 野生菌手帐 → 探索多模态 AI 在垂类 C 端工具的应用
- 个人多 Agent 助手 → 探索多 Agent 协同的能力边界
- 合同审阅助手 → 将垂直领域 RAG 能力复用到法律/商务场景

**Agent 实验田已发布作品**:失恋陪伴助手、AI 情感伴侣 V1(Coze 平台,提示词主导 + 三层记忆架构:碎片/短期/长期)。诚实定位为"对 C 端情感陪伴方向的技术验证 Demo"。

**开发策略(重要)**:分两步。
- **V1**:地图先用"静态分区图 + 普通项目卡片"代替复杂交互,先把内容立起来。
- **V2**:升级为完整放大镜交互(鼠标跟随 + 地块热区 + 缩放跳转)。
- **移动端**:放大镜交互在触屏失效,必须设计降级方案(如点击直接展开,不依赖 hover)。

### 第五幕:视觉与生活(人格魅力)

**作用**:让 HR 从"评估你能不能干活"切换到"想认识你这个人"。基调 **克制的真诚**,不要变成朋友圈/生活秀。

**三个小块**:
1. **视觉创作(主体)**:手绘作品画廊 + 摄影 + AIGC 作品并置,讲"传统功底 × AI 延伸"的故事。
   - **绘画是王牌**:素描有**专业 8 级证书**(明确标出,这是有官方背书的硬资质),媒介多样(素描/水彩/刀画/丙烯/速写)。
   - AIGC 作品:那张城市轴测图放这里,它身上的规划专业标注正好证明"带专业知识在用 AI"。
   - `【待回填:绘画作品选图、摄影选图】`
2. **生活切片(轻量)**:3D 打印(呼应"爱动手、把想法变实物"人设)+ 骑行(活力、爱探索)。一两句话点到即止。`【待回填:图片】`
3. **我的书架**:四类(AI / 商业分析 / 产品经理 / 哲学),均真实在看。
   - **铁律**:只放真读过、聊得出来的书(面试可能被问)。
   - **杀招**:每本(或重点书)配一句本人的读后感/为什么读 → 把"书架"变成"你的大脑"。
   - `【待回填:真实书单 + 每本一句话感想】`

### 第六幕:收尾(背书与联系)
